1. 使用者與照護圈模組：

users（使用者）
Column NameDatatype PKNNUQAIDefault/Expression
_idObjectId
emailString(255)
passwordHashString
nameString
roleStringpatient / family / caregiver
emailVerifiedBooleanfalse
linkedPatientEmailString目前操作長輩
inviteCodeString長輩邀請碼
langStringzh
healthCardObject血型／過敏／病史等
createdAt / updatedAtDatetimestamps

users（使用者資料表）：記錄三角色帳號。email 為登入唯一帳號，密碼以 passwordHash 加密存放；role 區分受顧者／看護／家屬。健康資訊卡存在 healthCard 內嵌物件，供急救與語言隔閡使用。

carecirclemembers（照護圈成員）
Column NameDatatype PKNNUQAIDefault/Expression
_idObjectId
patientEmailString長輩 email
memberEmailString看護或家屬 email
roleInCircleStringfamily / caregiver
joinedAtDateDate.now

carecirclemembers（照護圈成員表）：以 patientEmail＋memberEmail 唯一對應一位長輩與看護／家屬。roleInCircle 記錄其在圈內角色。SOS、待辦、監看都依此圈過濾。

2. 求救、異常與影像模組：

sosevents（SOS 呼叫）
Column NameDatatype PKNNUQAIDefault/Expression
_idObjectId
eventIdString
patientUserIdObjectId → users
message / messageKeyString需要幫忙／跌倒／快來
statusStringactive / handling / resolved / cancelled
handlerUserIdObjectId → users處理人
triggeredAtDateDate.now

sosevents（SOS 呼叫表）：長輩按呼叫後寫入。以 patientUserId 關聯使用者，status 記錄進行中／處理中／已處理／已取消。看護一鍵「標記為已處理」寫入 handlerUserId。

abnormalevents（跌倒／異常事件）
Column NameDatatype PKNNUQAIDefault/Expression
_idObjectId
eventIdString
patientUserIdObjectId → users
type / severityStringLow～Critical
statusStringPending / Processing / Done
claimedByUserIdObjectId → users看護已查看
sourceEventKeyString對應影像 frameTag
evidence[]Array截圖／短片 objectKey

abnormalevents（異常事件表）：跌倒等偵測結果。High 未起才升級；看護一鍵已查看寫 claimedByUserId，不必填如何處理。evidence 掛監看截圖與短片。

visiondetectionrecords／camerasessions
Column NameDatatype PKNNUQAIDefault/Expression
patientUserIdObjectId → users
action / severityString跌倒、彎腰等
frameTagString對應證據
alertBuiltBooleanfalse（未起才建警報）
startedAt / endedAtDate鏡頭在線區間

visiondetectionrecords 存每筆姿勢偵測；彎腰僅記錄不推播。camerasessions 記鏡頭開／關區間，供監看時間軸上色（連續畫面檔在本機，不上雲）。

3. 待辦、提醒與日常照護模組：

tasktemplates（提醒範本／每日重複）
Column NameDatatype PKNNUQAIDefault/Expression
_idObjectId
patientUserIdObjectId → users
createdByUserIdObjectId → users
category / contentString用藥、洗澡等
time / times[]StringHH:MM
weekdays[]Number[]＝每天

tasktemplates（提醒設定表）：家屬新增的重複待辦範本。每日依 time 展開成當日 reminders 勾選項。

reminders（當日待辦／完成紀錄）
Column NameDatatype PKNNUQAIDefault/Expression
_idObjectId
reminderIdString
patientUserIdObjectId → users
content / categoryString
timeDate預定時間
isCompletedBooleanfalse
completedByUserIdObjectId → users執行看護／家屬
marStatus / givenAtString / Date用藥紀錄

reminders（待辦紀錄表）：當日待辦與完成紀錄。看護「確認並同步」寫 isCompleted、completedByUserId。完成紀錄頁讀已完成列。

caredailyrecords（日常照護紀錄）
Column NameDatatype PKNNUQAIDefault/Expression
patientUserIdObjectId → users
createdByUserIdObjectId → users
category / contentString飲食、用藥等
sleep / bloodPressure / heartRate / temperatureString當日觀察
recordedAtDateDate.now

caredailyrecords（日常紀錄表）：看護填寫飲食等，家屬／長輩可看。以 patientUserId 掛在照護圈長輩下。

4. 生理量測與訊息模組：

bloodpressurerecords（血壓）
Column NameDatatype PKNNUQAIDefault/Expression
_idObjectId
userIdObjectId → users長輩
sys / diaNumber收縮／舒張
pulseNumber
levelString正常／偏高等
measuredAtDateDate.now
sourceStringmanual-entry / Health Connect
syncKeyString去重

bloodpressurerecords（血壓紀錄表）：手動輸入或 Health Connect 同步。

chatmessages／customphrases（訊息與快捷語）
Column NameDatatype PKNNUQAIDefault/Expression
senderEmail / targetEmailString對話雙方
originalText / translatedTextString原文／譯文
kindStringtext / voice
audioObjectKeyString語音檔
timestampDateTTL 30 天
ownerEmail / textString快捷語

chatmessages 存跨語對話與語音；customphrases 為各角色快捷語。chatvoiceassets 登記語音檔。
